What the app does

ScanReady reads a patient's appointment documents (PDFs in docs/) and builds a calm plan: when to arrive, what to do, and what might block them. It drafts requests to the imaging center and answers questions only when the documents support the answer. Otherwise it says it doesn't know and suggests a question for the center.

  • Frontend (frontend/): plain HTML, CSS and JavaScript, served by the backend.
  • Backend (backend/app/): FastAPI. It loads the PDFs, calls OpenAI (gpt-5.4-mini) and checks every quote against the source text.
  • Documents (docs/): five fictional PDFs.

One action, end to end: “Build my plan”

Reference route (not toured interactively)

  1. Entry: frontend/app.js → search async function buildPlan. It POSTs to /api/plan and hands the result to renderPlan.
  2. Logic: backend/app/plan.py → build_plan tries _live_plan, falls back to backend/cache/plan.json if the call fails, and _grounded drops any item whose quote isn't in its source document.
  3. Result: frontend/app.js → renderPlan draws the headline, the discrepancy note, tasks and blockers with their source quotes.

Pointers
  • Wording of the won't-guess reply: backend/app/ask.py → WONT_GUESS.
  • Which barriers are offered: backend/app/draft.py → BARRIERS.
  • Colors and type: frontend/styles.css → the variables at the top.
  • Which documents are read: add or replace PDFs in docs/; backend/app/documents.py → load_documents.
  • Model choice: backend/app/ai.py → MODEL.

A practice to reuse

Decision: make the safety rule observable. The PRD says medication questions must not be guessed, and backend/app/ask.py enforces it in code: if the model says the documents don't answer, or no citation matches the source text, the fixed WONT_GUESS reply is returned.

Evidence: a build check asked about medication, a pacemaker and a contrast allergy and got the fixed reply each time. It also asked about fasting and arrival time and got cited answers.

Reuse: on another AI project, write the “must never” rule as something a script can check, and enforce it in code rather than only in the prompt.

Run it again

From backend/: .venv\Scripts\python.exe -m uvicorn app.main:app --port 8010, then open http://localhost:8010. Needs backend/.env with your own OPENAI_API_KEY (see backend/.env.example).
